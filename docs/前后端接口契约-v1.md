# 前后端接口契约 V1（去 Mock 第一阶段）

本文档用于把 `froned/src/api/index.js` 从模拟实现切换为真实后端接口。

## 1. 全局约定

- Base URL：`/api/v1`
- 鉴权：`Authorization: Bearer <token>`（登录后返回）
- 通用成功响应：
  - `{"code":0,"data":{...},"message":"ok"}`
- 通用失败响应：
  - `{"code":<非0>,"message":"错误信息"}`
- 分页请求参数：`page`（>=1）、`size`（1~100）
- 分页返回：`{"items":[...], "total":123}`
- 时间统一：ISO8601（如 `2026-04-13T10:20:30Z`）
