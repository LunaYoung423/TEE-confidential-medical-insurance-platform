# 医保理赔数据集（new_data / medical_insurance_claims）接入说明

## 背景

- 原 `train_data.csv` / `test_data.csv` 为**回归**场景（标签 `actual_payout`）。
- 新数据集为**二分类**（标签 `claim_flag`），且含字符串字段（性别、ICD-10、日期），**不能**直接交给 `module2.utils.data_loader`（其要求除最后一列外均为数值）。

## 需要改动的文件（已在本仓库中完成）

| 文件 | 作用 |
|------|------|
| `scripts/prepare_medical_claims_csv.py` | 将原始理赔 CSV 转为纯数值训练/验证 CSV |
| `module2/algorithms/xgboost_classifier.py` | XGBoost **分类**算法（预测 claim_flag） |
| `module2/algorithms/__init__.py` | 注册算法名 `xgboost_classifier` |
| `scripts/integrated_client.py` | 默认使用理赔数据路径、`xgboost_classifier`，并修正 Docker 下密文 `file://` 路径 |
| `scripts/evaluate_claims_model.py` | （可选）本地评估解密后的模型 |

**无需改**：`module2/main.py`、`module2/utils/data_loader.py`（仍读「数值 CSV + 最后一列标签」）。

## 阿里云 / Docker 推荐步骤

### 1. 上传项目并准备数据

将 `new_data.csv` 放到项目 `data/` 目录（与 `docker-compose.yml` 中 `./data` 卷一致）。

### 2. 生成数值化 CSV

在**宿主机**（系统 **Python 3.8**，已 `pip3 install -r module1/requirements.txt -r module2/requirements.txt`）执行：

```bash
cd confidential-computing-platform
python3.8 scripts/prepare_medical_claims_csv.py \
  --input data/new_data.csv \
  --train-out data/train_claims_numeric.csv \
  --val-out data/val_claims_numeric.csv \
  --train-size 2000
```

- 训练服务 `Config.MIN_SAMPLES = 2000`，训练集行数需 **≥ 2000**。
- 若全量不足 2000 行，需合并数据或暂时调低 `module2/config.py` 中的 `MIN_SAMPLES`（不推荐生产环境随意调低）。

### 3. 启动栈并跑通密态训练

`docker-compose` 里的 `cc-client` 镜像**默认未复制** `scripts/integrated_client.py`，请在**宿主机**进入项目根目录执行（依赖安装见 `docs/四要点分步测试操作手册.md` 的 **G1**）：

```bash
cd /path/to/confidential-computing-platform
export PYTHONPATH=/path/to/confidential-computing-platform
# 宿主机上 data 目录的绝对路径（与 compose 中 ./data 为同一目录）
export CLIENT_DATA_DIR=/path/to/confidential-computing-platform/data
export TRAINING_CONTAINER_DATA_DIR=/app/data
export TRAIN_DATA_PATH=/path/to/confidential-computing-platform/data/train_claims_numeric.csv
export TRAIN_ALGORITHM=xgboost_classifier
export CONTROLLER_URL=http://<宿主机IP>:8080
export VERIFY_URL=http://<宿主机IP>:8081
python3.8 scripts/integrated_client.py
```

- `CLIENT_DATA_DIR`：密文 `encrypted_train_data.bin` 写入位置（宿主机可见）。
- `TRAINING_CONTAINER_DATA_DIR`：训练容器内挂载的同一 `data` 目录，一般为 `/app/data`（见 `docker-compose.yml` 中 `confidential-container`）。

**仅在「训练进程能直接打开与 CLIENT_DATA_DIR 相同的绝对路径」时**才需要：

```bash
export TRAINING_USE_LOCAL_FILE_URI=1
```

### 4. （可选）评估模型

将工作流生成的 `model_<task_id>.pkl` 拷到本地后：

```bash
python3.8 scripts/evaluate_claims_model.py --model model_xxx.pkl --val data/val_claims_numeric.csv
```

## 算法说明

- 理赔核验 / 欺诈分析等若建模为 **是否理赔**，使用 `logistic_regression` 或 `xgboost_classifier`。
- 若仍要做**金额回归**，需要数据集中有连续金额标签，并继续使用 `xgboost`（回归）与对应格式的 CSV。

## 特征说明（prepare 脚本输出列）

`age`, `gender`(0/1), `visit_month`, `visit_day`, `diagnosis_code`(整数码), `drug_cost`, `test_cost`, `total_cost`, **`claim_flag`（标签）**
